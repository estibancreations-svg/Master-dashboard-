## Version: v3.0.0-weaver

### Architectural Phase Profile
This phase represents the birth of the **Pipeline Weaver**, a step-by-step visual execution simulation modeling data transformations across 4 nodes (Drive input, Prompt enhancement, Format transformation, n8n webhook dispatch).

### Conserved Elements
- **Visual Node Topology Editor**: Modular drag-and-drop/interactive pipeline graph configuration tool.
- **Monochrome Sandbox Terminal Simulator**: Detailed, high-contrast console log stream displaying exact execution delays and step outcomes with millisecond timing parameters.
- **Node Configuration Inspectors**: Dedicated sub-forms for managing individual node fields (aspect ratio, custom prompts, n8n webhook targets).
- **Export Topology (Backup Backbone)**: Safe serialized offline JSON export of pipeline state vectors.
- **Proxy Outbound Dispatches**: Express backend proxying (`/api/dispatch-n8n`) to securely dispatch binary payload arrays to automated servers like n8n, bypassing CORS limits.
